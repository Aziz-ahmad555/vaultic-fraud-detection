\subsection{Training}
% Out-of-sample view predictions, view dropout, weighted BCE, cost-weighted variant (7.3).

% Required disclosure (research/decisions.md D140, phase3-run review #1):
The gate is trained on cross-fitted, out-of-time view predictions (decision D95): three
expanding-window folds over the training period and one fixed fold. Within each cross-fitted
fold, the view models were trained on every label of their training window, including labels
that a 30-day label delay would not yet have released when the fold's predicted block starts;
the same holds for the fixed fold's predictions on validation days 128--143, which are also
gate-training rows. The gate therefore learned from view scores slightly better informed than
those available in deployment. The view models that score the test period are trained on days
1--120 and use only labels released before the test period begins. A post-hoc sensitivity
analysis rebuilds the cross-fitted folds with 30-day label maturity (D141).
